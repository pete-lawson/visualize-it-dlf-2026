# Visualize It: Designing Impactful and Accessible Data Visualizations

A workshop by Peter Lawson at the [Virtual DLF Forum 2026](https://forum2026.diglib.org/), October 15, 2026.

**Workshop website:** <https://pete-lawson.github.io/visualize-it-dlf-2026/>

## Abstract

Data visualization is essential in library work, yet few practitioners receive formal training in it. This workshop equips library professionals at any level with a practical foundation in the design of accessible and effective data visualizations, combining theory with hands-on practice, leaving participants with a framework they can immediately apply.

## Learning objectives

After completing this workshop, attendees will be able to:

- Explain how principles of visual perception inform effective data visualization design.
- Evaluate a data visualization by identifying specific design and accessibility strengths and weaknesses using a structured framework.
- Apply design principles, such as color selection, typography, labeling, and accessibility guidelines to revise a data visualization for clarity and impact.
